# 选题分析API集成说明

## 功能概述

已成功集成公众号文章搜索API到选题分析页面，提供以下功能：

### 1. API服务
- **API端点**: `/api/wechat-proxy` (内部代理)
- **外部API**: `https://www.dajiala.com/fbmain/monitor/v3/kw_search`
- **API密钥**: `JZL0a2b0298ebcb567c`

### 2. 核心功能
- ✅ 根据关键词搜索公众号文章
- ✅ 获取文章数据（标题、内容、阅读量、点赞数等）
- ✅ 自动生成文章摘要
- ✅ 提取高频词汇生成词云
- ✅ 分析数据并生成洞察报告
- ✅ 计算互动率和排序
- ✅ 导出分析报告功能

### 3. 数据处理
- **文章转换**: API数据 → 应用内部数据结构
- **摘要生成**: 自动截取文章前200字符，在标点符号处智能截断
- **互动率计算**: (点赞数 + 在看数) / 阅读数 × 100%
- **词频分析**: 过滤停用词，统计高频词汇
- **数据洞察**: 分析热门公众号、原创比例、平均互动率等

### 4. 错误处理
- ✅ CORS问题处理（通过内部代理）
- ✅ API响应错误处理
- ✅ 网络请求异常处理
- ✅ 无数据结果处理
- ✅ 用户友好的错误提示

### 5. UI交互
- ✅ 加载状态显示
- ✅ 错误信息展示
- ✅ 实时分析反馈
- ✅ 一键导出报告
- ✅ 重新分析功能

## 使用方法

1. 访问 `http://localhost:3001/analysis`
2. 在搜索框输入关键词（如：人工智能、AI技术等）
3. 点击"开始分析"按钮
4. 等待分析完成，查看结果
5. 可以导出报告或基于洞察创作内容

## 技术实现

### 类型定义 (src/types/api.ts)
- `ApifoxModel`: API响应模型
- `Datum`: 单篇文章数据
- `ArticleData`: 转换后的文章数据
- `ApiRequestParams`: API请求参数

### API服务 (src/services/wechatApi.ts)
- `fetchWeChatArticles()`: 主要获取函数
- `fetchWeChatArticlesDirect()`: 备用直接调用
- `transformArticleData()`: 数据转换
- `extractKeywords()`: 关键词提取
- `generateInsights()`: 洞察生成

### 代理API (src/app/api/wechat-proxy/route.ts)
- 处理CORS问题
- 代理外部API请求
- 错误处理和响应转发

## 注意事项

1. **API限制**: 使用提供的API密钥，请注意调用频率
2. **数据准确性**: 依赖外部API数据质量
3. **网络依赖**: 需要稳定的网络连接
4. **CORS处理**: 通过内部代理避免浏览器CORS限制
